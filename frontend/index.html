First setup

where is your music?

Point Cadence at a folder that already exists on this server. Or use the built-in library, which is stored in AppData and removed if that AppData folder is deleted.

This folder has to exist already. On a CasaOS server, it is usually somewhere under /DATA. The same can be said for any other server.

Kept in AppData. On CasaOS that folder is /DATA/AppData/cadence/library. On any other system it is the library folder next to the app. If that folder is deleted, the built-in library goes with it.

Success. Your library is set.
